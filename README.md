## Selected work

### 🌱 [Fidan](https://github.com/fidan-lang/fidan)

Creator and primary developer of **Fidan**, an AI-native general-purpose programming language and compiler toolchain built in Rust.

Fidan includes static type checking, typed HIR/MIR, an interpreter, Cranelift JIT/AOT, optional LLVM AOT, an LSP, package tooling, concurrency primitives, and compiler-grounded AI workflows.

**Rust · Compilers · Cranelift · LLVM · JIT/AOT · LSP · AI Tooling**

---

### 🚦 [LanePilot](https://github.com/AppSolves/LanePilot)

Deep-learning traffic management system combining real-time computer vision, graph-based traffic optimization, and edge deployment.

Built with **PyTorch, YOLO11n-seg, PyTorch Geometric / GATv2, TensorRT, CUDA, NVIDIA Jetson, and Raspberry Pi**.

**Deep Learning · Computer Vision · GNNs · Edge AI · TensorRT**
